# ☕ Coffee!

Een webapp voor mijn dagelijkse lespraktijk: je lesdag in één oogopslag, rechtstreeks uit de weekagenda's op de gedeelde schooldrive.

- **Nu:** het huidige lesuur met doelen, verloop, materiaal en links, therapie, herinneringen en de vorige les in dezelfde reeks.
- **Week:** het weekoverzicht, per dag.
- **Instellingen:** Google-koppeling, agendamap, zwemritme (½ P) en testtijd.

Alle gegevens blijven in Google Drive; deze repo bevat enkel code.
`test.html` is de verbindingstest.

Testtijd via de adresbalk: `?nu=2026-11-24T09:45`
